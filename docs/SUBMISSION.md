## 验证记录的阅读方式

当前源码、历史实验与本次整理检查分别判断：

1. 当前代码能否运行，以所选环境中的命令退出码和日志为准。
2. 历史 GPU 实验是否成立，以同一次运行的配置、退出记录、候选、执行回执和验证结果为准。
3. 静态结构检查、单元测试、进程内 HTTP、真实 socket、浏览器交互和视觉检查属于不同层级，不能相互替代。

本次整理使用现成 Python 3.12 环境完成以下检查：

| 检查范围 | 本次结果 | 说明 |
|---|---|---|
| 主工程默认测试 | 229 项，226 通过、3 跳过，退出码 0 | 3 项为未启用的本机 `.venv`、`.env` 和编辑器配置检查 |
| 现场演示 Python 测试 | 25 项全部通过 | 覆盖模型、自定义拓扑和进程内 HTTP handler |
| 现场演示 DOM 交互 | 10 项全部通过 | 使用模型输出检查前端交互，不检验浏览器 CSS 排版 |
| 仓库静态检查 | 341/341 通过 | 含 313 个证据文件哈希、vendor 与根源码同源关系、11 个 GPU 生产源码与实际执行快照匹配 |

真实 TCP 和 CPU Gloo 测试类由默认运行器显式排除，`--live` 本次未运行。本轮没有下载依赖、绑定本地监听端口或重新运行 GPU 实验；默认套件包含已有的受控 sleep 子进程清理测试。Docker 启动与真实浏览器视觉尚未实测。以上结果只对应本次整理后的检查范围，不能扩展成全部执行后端或部署环境均已验收。

从仓库根目录复查：

```bash
.venv/bin/python scripts/run_tests.py
.venv/bin/python scripts/check_repository.py
```

默认测试覆盖领域逻辑、进程管理和进程内 API，无需真实网络或 GPU。部分测试会启动受控子进程检查清理逻辑，因此不是全部在同一进程内完成。环境允许本地通信且具备对应依赖时，可额外运行：

```bash
.venv/bin/python scripts/run_tests.py --live
```

`--live` 包含真实 localhost TCP 和 CPU Gloo 进程测试，后者需要 PyTorch。`--local-env` 是原本机环境约定的可选检查，会核对 `.venv`、`.env` 和编辑器配置，不是搬迁仓库后运行核心功能的前提。

现场演示的模型、拓扑和进程内 handler 检查见 [快速开始](QUICKSTART.md)。真实 GPU 实验需另行分配资源并执行，不随默认检查自动运行。

## 实验结论与限制

- v2 的完成时间、TTFT 与容量曲线来自给定配置和模型抽象。仿真器不运行真实 GPT-2/Qwen 权重，也不复现完整 NCCL 协议。
- 2026-11-03 的 GPT-2 Small 四组对照为单机 3090 实验，每组一次。它们证明当次受控 worker 退出、完整组重建、检查点恢复和最终进度，尚不足以形成统计可靠性或跨主机故障结论。
- 受控 worker 退出不等于 GPU 硬件损坏；策略隔离执行槽不等于硬件根因诊断。
- 本地 GPU 证据导出包不含检查点二进制。manifest 与哈希记录能追溯服务器上的验证过程，不能代替重新检查原始检查点文件。
- worker 退出到首个双 rank 恢复步约 12.552 s；故障至控制器终态约 94.940 s，后者包含剩余训练与验证，不能标为纯恢复时间。
- 现场 TCP 采用回环通信和应用层通道切换，不代表 RDMA、交换机或跨主机 GPU 网络恢复。历史证据回放必须注明来源。
- 平台和 Agent 目前按课程实验原型设计。Web 未直接调度真实 GPU，账户隔离、跨重启事务、动态资源复核与性能感知恢复策略仍有缺口。

## 交付与后续发布

源码与证据是课程评审的基础，汇报 PPT 不替代正式报告。团队应按课程要求核对报告篇幅、核心 API、数据契约、分工、Assistant、权限、性能、未实现内容及风险说明。个人贡献以真实提交和实验记录为准，不能从任务表直接推断。

准备后续发布时，在本地确认：

- 根 README 和文档中的相对链接可用，主平台、现场演示与真实 Agent 入口清楚。
- 新运行结果写到新的 `results` 或 `var` 目录，不覆盖已有证据。
- 提交内容不包含虚拟环境、依赖缓存、运行数据库、令牌、私密配置或大体积检查点。
- 实验源码与结果版本对应，阶段性报告和历史状态说明有明确标记。
- 团队决定仓库可见性、许可证和最终提交内容后，再进行远程发布。

本轮仅整理本地仓库，不执行 `git init`、提交或推送，也不替团队指定开源许可证。
