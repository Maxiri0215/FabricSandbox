# 公开版本脱敏说明

2026-11-10，本仓库在首次公开上传前进行了脱敏。静态检查未发现私人登录凭据；个人目录、主机名称、GPU UUID 和 PCI 地址使用一致的匿名标识。

## 处理范围

- 本机和服务器目录中的个人用户名替换为 `project-user`；这些目录是历史记录中的占位路径，不是接收者需要创建的运行目录。
- 容器或服务器主机名称替换为匿名名称。
- GPU UUID 和 PCI 地址按设备索引建立一致的匿名映射；同一设备在预检、rank 记录、恢复验证和演示回放中仍能相互对应。
- Git 提交作者和提交者使用公开用户名及隐私邮箱；当前分支的首次提交已经重建，普通推送不会包含被替换的旧提交。
- 忽略规则补充了常见私人环境配置、SSH 密钥、云服务凭据和服务账号文件。

## 证据含义与校验

脱敏没有重新运行 GPU 训练。训练设置、数值指标、时间戳、故障与恢复事件、rank/槽位对应、进程 PID、进程启动标识和检查点摘要保持原记录含义。公开 UUID 是匿名标识，不能据此识别或连接原实验设备。

`evidence/public_release.json` 标记公开副本的处理范围。`evidence/evidence_manifest.json` 校验当前公开文件的大小和 SHA256。演示 `demos/live/data/gpu_sources.json` 中的来源和输出摘要也针对脱敏后的公开副本。

历史 `SHA256SUMS`、`sha256_*.json`、`source_*_manifest.json`、复制记录中的 `source_sha256`、`docs/source_import.json` 等继续记录当时导出或导入时的摘要；它们不等同于脱敏副本的新摘要。原文件没有包含在仓库时，不声称已在本机重新校验。检查点权重未随仓库提供，其摘要仍是原始执行记录中的值。

Agent 和仿真内核源码未因身份脱敏而改变。历史执行源码与当前生产模块的字节对应关系，仍由 `scripts/check_repository.py` 检查。设备身份在实际实验时的检查结果被保留；公开副本能复核匿名标识的一致性，不能独立证明原物理设备身份。

## 后续维护

不要把 Token、私钥或真实 `.env` 写入源码、日志或截图。`.env.example` 的空令牌字段用于说明配置方式；测试字符串和本地开发数据库默认密码不是私人凭据，部署时应使用独立配置。

修改公开证据后，应同步更新外层证据清单；重新导出 GPU 演示时，应从带脱敏标记的公开证据目录读取。原始资料仍保存在仓库之外，匿名映射不随仓库发布。
