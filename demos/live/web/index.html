现场讲解

三分钟演示指南

  1. 网络方案评估 约 1 分钟

    分析默认的 50 Gbps 场景，指出共享上联的竞争。展开候选与拒绝理由，再采用推荐放置、比较结果。可切换显存不足，展示系统如何拒绝不可行方案。

  2. 真实通信故障 约 1 分钟

    启动真实传输，确认数据已收到 ACK。注入主通道故障，观察规则 Agent 自动诊断、选择备用路径，并用新数据的校验与确认验证恢复。

  3. 3090 实测证据 约 1 分钟

    沿七个阶段查看同一次 DDP 事件：step7 异常、候选选择、从 step5 恢复，再用 step6、step8 和最终 step20 解释新进度。

讲清每种证据的范围

网络方案：原项目模型在本机重新计算，时间与容量属于仿真。

TCP 实验：本机实际进程、连接和数据传输；不代表真实 GPU 链路故障。

GPU 记录：服务器历史实测，供逐项核对恢复证据。

本演示本地运行，恢复决策采用规则策略，不调用外部大模型。
